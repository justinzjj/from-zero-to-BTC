## 课程架构图约定

后续绘制全节点和矿池／矿场架构图时，沿用[钱包组成图](lessons/overview/btc-wallet.html)的风格。打开图 1 中对应的设备或程序，用外框标出职责边界，每个组件只画一次。相邻职责并排，共用组件放在相关模块之间。实线表示内部调用或数据读取，虚线表示跨边界交互；在线旁写出传递的具体数据，并注明本地回调或跨设备消息。在重点组件内标注所用算法、关键数据结构及其用途。先以简图讨论，再制作 HTML。
