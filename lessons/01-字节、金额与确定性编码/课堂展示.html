整数金额 Amount

如何避免小数舍入进入付款计算？

1 BTC = 100,000,000 聪
  • 金额存为 int64_t，小数只出现在输入和展示层。
  • 整数适合比较、求和、费用与找零；仍然需要溢出保护。
  • MAX_MONEY = 21,000,000 × COIN，是范围上限，不是本课实现的发行规则。
表达含义
0.00060000 BTC60000 聪
Amount8 字节有符号整数
CAmount / MoneyRangeBitcoin 类型 / 范围判定

十进制金额解析算法

怎样从文本精确得到整数聪？

A = w × 10⁸ + f × 108−d
扫描字符整数逐位累加小数最多8位补零到8位检查金额范围
  • w 为整数部分，f 为小数数字整数，d 为小数位数。
  • 执行 w = 10w + digit 前，检查 w ≤ (limit − digit) / 10。
  • 只接受数字和一个小数点；拒绝符号、空白、科学计数法、9位小数。

O(L) 时间、O(1) 辅助空间；教学输入上限32字符。Core ParseMoney 会 TrimString，并返回 optional；教学接口失败抛异常。

小端整数编码

同一个整数怎样得到相同字节？

bᵢ = (v ≫ 8i) & 255　　v = Σ bᵢ · 28i
60000 = 0xEA60

小端：60 ea 00 00 00 00 00 00
大端：00 00 00 00 00 00 ea 60
  • 1字节 = 8位 = 2个十六进制字符。
  • 编码和解码使用无符号移位。
  • 解码先放入 uint64_t，检查范围后转换 Amount。

字节序由协议规定，不能依赖当前机器的内存顺序。

Reader 与有界反序列化

怎样拒绝截断、额外字节和越界金额？

总长 = 13version = 1读取 recipient读取 amount金额范围检查
  • Reader = 字节引用 + pos，保持 0 ≤ pos ≤ size。
  • 先检查剩余长度，再读取并推进游标。
  • 时间 O(n)，固定字段的只读解析辅助空间 O(1)。
  • Core SpanReader 用剩余 span 表示读取状态。
  • ReadCompactSize 拒绝非最短表示，例如用 fd 01 00 表示1。
  • Core 流可连续读取对象；是否禁止尾随数据由调用层决定。

解析成功只说明格式合规，不说明有钱、已授权、未双花。教学只接受版本1，不代表 Bitcoin 只能接受版本1。

基础知识 / 10

SHA-256：分块、填充与压缩

固定长度摘要如何从消息字节产生？

追加1位与零填充附加64位原始位长度512位分块64轮压缩输出256位
  • 每块64字节；形成16个32位大端字，再扩展为64个字。
  • 8个32位工作寄存器逐轮混合，结束后累加进状态。
  • SHA内部大端读字，与草稿字段的小端序属于不同层次。
块数 = ⌈(n + 9) / 64⌉

O(n) 时间、流式常量工作空间。13字节草稿需要1块；双SHA-256的第二次32字节输入再需要1块。

SHA-256：消息扩展与一轮计算

一位输入变化怎样进入后续状态？

Wₜ = σ₁(Wₜ₋₂) + Wₜ₋₇ + σ₀(Wₜ₋₁₅) + Wₜ₋₁₆
T₁ = h + Σ₁(e) + Ch(e,f,g) + Kₜ + Wₜ
T₂ = Σ₀(a) + Maj(a,b,c)
函数位运算
Ch / Maj(x∧y)⊕(¬x∧z) / (x∧y)⊕(x∧z)⊕(y∧z)
Σ₀ / Σ₁右旋 2、13、22 / 6、11、25 后异或
σ₀ / σ₁右旋7、18与右移3 / 右旋17、19与右移10 后异或

所有加法模 2³²；每轮 a=T₁+T₂、e=d+T₁，其余寄存器顺移。理解流程并调用成熟库，不要求手写64轮。

基础知识 / 13

哈希摘要的保证边界

攻击者修改金额后，为什么仍能得到合法摘要？

  • 保证：相同输入得到相同输出；依赖抗碰撞、抗原像性质。
  • 不保证：没有碰撞、付款者身份、消息保密。
  • 双哈希输出仍为32字节，安全强度不简单翻倍。
原草稿 → SHA256 → 摘要 A
改金额 → SHA256 → 摘要 B

攻击者也能计算 B。

13字节草稿的摘要反而更长。摘要的价值是固定长度与索引，不是每次都压缩。

代码：金额解析与溢出检查
为什么必须先检查，再执行乘10？
inline Amount parse_amount(const std::string& s) {
    require(!s.empty() && s.size() <= 32, "amount length");
    Amount whole=0, fraction=0; unsigned digits=0; bool dot=false, before=false;
    for (char c:s) {
        if (c=='.') { require(!dot && before,"decimal point"); dot=true; continue; }
        require(c>='0' && c<='9',"amount character"); int d=c-'0';
        if (!dot) { before=true; require(whole <= (21000000-d)/10,"amount overflow"); whole=whole*10+d; }
        else { require(digits<8,"amount precision"); fraction=fraction*10+d; ++digits; }
    }
    require(!dot || digits>0,"empty fraction");
    while(digits<8) { fraction*=10; ++digits; }
    Amount value=whole*COIN+fraction; require(value<=MAX_MONEY,"amount range"); return value;
}
关注三处约束：整数上界、小数8位、合并后的 MAX_MONEY。失败不返回“近似金额”。

代码：草稿编码与解码
怎样把类型契约变成可执行检查？
inline Bytes encode(const PaymentDraft& d) {
    require(d.amount>=0 && d.amount<=MAX_MONEY,"draft amount");
    Bytes b; b.reserve(13); b.push_back(1); put_le(b,d.recipient,4); put_le(b,d.amount,8); return b;
}
inline PaymentDraft decode(const Bytes& b) {
    require(b.size()==13,"draft size"); Reader r{b}; require(r.le(1)==1,"draft version");
    auto recipient=static_cast<std::uint32_t>(r.le(4)); auto value=r.le(8);
    require(value<=static_cast<std::uint64_t>(MAX_MONEY),"draft range");
    return {recipient,static_cast<Amount>(value)};
}
reserve(13) 控制扩容；读取金额先用无符号类型；通过范围检查才转 Amount。

代码：小端读写
哪些原语会被交易、区块与网络复用？
inline void put_le(Bytes& b, std::uint64_t v, unsigned width) {
    require(width>=1 && width<=8,"integer width");
    for(unsigned i=0;i<width;++i) b.push_back(static_cast<unsigned char>(v>>(8*i)));
}
struct Reader {
    const Bytes& bytes; std::size_t pos=0;
    std::uint64_t le(unsigned width) {
        require(width>=1 && width<=8 && width<=bytes.size()-pos,"truncated integer");
        std::uint64_t v=0; for(unsigned i=0;i<width;++i) v|=std::uint64_t(bytes[pos++])<<(8*i); return v;
    }
};
put_le 按低字节到高字节写入；Reader::le 先检查长度，再推进游标。

代码：哈希与十六进制接口
如何明确区分原始字节、摘要与展示文本？
inline Hash256 sha256(const Bytes& bytes) {
    auto b=digest(bytes,EVP_sha256()); require(b.size()==32,"digest size"); Hash256 h{};
    std::copy(b.begin(),b.end(),h.begin()); return h;
}
inline Hash256 double_sha256(const Bytes& b) { auto h=sha256(b); return sha256(Bytes(h.begin(),h.end())); }
template<class T> inline std::string hex(const T& bytes) {
    const char* digits="0123456789abcdef"; std::string out; out.reserve(bytes.size()*2);
    for(auto b:bytes) { out+=digits[b>>4]; out+=digits[b&15]; } return out;
}
hex 将一个字节拆成两个4位索引；double_sha256 明确做两次SHA-256。第2讲 message 接口内部自带单次哈希。
