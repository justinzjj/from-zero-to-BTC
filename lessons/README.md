# 课程目录

每门课程使用独立目录，讲义、演示页面和该课程的辅助材料放在一起。通用知识卡片保留在本层，由各课程共同引用。

| 入口 | 内容 |
|---|---|
| [overview · BTC 总览](overview/README.md) | 从一笔付款理解钱包、全节点、矿机与交易生命周期 |
| [知识卡片](知识卡片/README.md) · [卡片阅读页](知识卡片/阅读.html) | 各课程共用的概念、算法与推演材料 |

后续课程在 `lessons/` 下新建与 `overview/` 并列的目录。课程引用卡片时使用 `../知识卡片/`，不复制卡片内容。需要自动标注术语的 HTML 可引入 `../知识卡片/术语引用.js`。
