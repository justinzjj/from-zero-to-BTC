# 01 · 哈希函数、原始字节与交易标识

哈希函数把任意长度的字节串映射成固定长度的摘要。同一种算法处理完全相同的字节，总会得到同一个结果。十六进制只是字节的书写方式。SHA-256 输出 32 字节，RIPEMD-160 输出 20 字节。双 SHA-256 把第一次的 32 个原始字节再哈希一次；HASH160 把 SHA-256 的结果交给 RIPEMD-160。

交易需要一个任何节点都能独立计算的名字。txid 用不含见证的基本序列化计算双 SHA-256，wtxid 用含见证的完整序列化计算。没有见证时两者相同。引用输出用 txid 和输出序号；按浏览器显示值对照原始字节时还要认清字节顺序。

**字节序。** 字节序描述多字节数值的排列顺序。节点哈希的是协议规定的字节串。常见工具显示 txid 时，使用与交易输入中前序哈希字段相反的字节顺序；核对时要先统一表示。

**输入与输出。** 用三个原始字节 `61 62 63` 计算 SHA-256，结果是 `ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad`。计算 txid 时换成交易的基本序列化字节，先取 SHA-256，再对所得的 32 字节取 SHA-256，最后反转摘要的字节顺序得到常用显示值。

**英文术语**　SHA-256（Secure Hash Algorithm 256-bit）、RIPEMD-160（RACE Integrity Primitives Evaluation Message Digest，160 位）、txid（transaction identifier，交易标识）、wtxid（witness transaction identifier，含见证交易标识）、BIP（Bitcoin Improvement Proposal，比特币改进提案）。
