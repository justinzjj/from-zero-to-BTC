# 02 · 私钥、公钥与压缩公钥

secp256k1 是 SEC 2（Standards for Efficient Cryptography 2）规定的曲线名称。在这条曲线上，私钥是从 1 到 n−1 的整数 d，n 是基点 G 的阶。公钥是曲线上的点 Q = dG。压缩公钥用 33 个字节表示同一个点：首字节 02 或 03 标明 y 的奇偶性，其余 32 字节保存 x 坐标。

这种对应关系把授权与核验分开。控制私钥的人可以签名，别人拿公钥即可验签；从公钥逆推出随机私钥在实践中不可行。压缩编码让钱包和节点用更少字节传递同一个点。

**编码一把公钥。** 取公开演算值 d = 2，则 Q = G + G。在有限域中倍点，斜率为 3x²/(2y)，新横坐标为斜率² − 2x，新纵坐标为斜率 × (x − 新横坐标) − y，各步模 p。此点的 y 为偶数，因此编码为 `02c6047f9441ed7d6d3045406e95c07cd85c778e4b8cef3ca7abac09b95c709ee5`。首字节之后的 32 字节就是横坐标。
