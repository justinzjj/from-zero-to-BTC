# 03 · 分层确定性钱包与扩展密钥

分层确定性钱包（HD 钱包）用一份种子建立一棵密钥树。BIP32 的每个树节点都有密钥与链码；两者合在一起构成派生下一层所需的核心材料。一条路径记录从根到这个位置所经过的子编号。采用 BIP39 的钱包可用助记词和可选口令得到种子。

钱包可以为不同付款给出不同的收款地址，并从同一根材料重建这些密钥。收款和找零可以各用一个分支。普通派生允许观察钱包用扩展公钥生成子公钥；硬化派生需要父级私钥材料。恢复时还要知道钱包采用的派生路径和脚本类型。

**种子与密钥的区别。** 种子是生成根节点的起点。BIP32 从种子计算出主私钥和主链码。一个普通私钥足以算出自己的公钥，扩展私钥还包含继续派生所需的链码。Bech32 地址则来自某个子公钥对应的收款条件，是可以交给付款人的信息。

**一层普通子私钥如何计算。** 输入父私钥 k、32 字节父链码 c、4 字节大端下标 i。计算 `HMAC-SHA512(key=c, data=压缩父公钥 || i)`，将 64 字节结果切为左右两半 L、R。左半按大端解释为整数；在有效情形，子私钥等于 (L + k) mod n，子链码等于 R。硬化派生将消息前段换成 `00 || 32字节父私钥`，下标从 2³¹ 起。L ≥ n 或所得子私钥为零时须改用下一下标。扩展密钥的序列化共有 78 字节，依次为版本 4、深度 1、父指纹 4、子编号 4、链码 32、密钥数据 33。

**英文术语**　HD（Hierarchical Deterministic，分层确定性）、HMAC-SHA512（Hash-based Message Authentication Code using SHA-512）、BIP（Bitcoin Improvement Proposal，比特币改进提案）。
