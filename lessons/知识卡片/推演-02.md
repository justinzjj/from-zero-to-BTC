# 用公开小整数演算公钥

收款钱包先取得一个私钥整数 d，或从已有的扩展公钥派生相应公钥。给定私钥时，用 secp256k1 规定的基点 G 做标量乘法，得到唯一公钥点 Q。将来花 B:0 时，Bob 才用相应私钥签名。

**手算一个和 B:0 对得上的例子。** 曲线上每个点有 x、y 两个坐标，满足 `y² ≡ x³ + 7 (mod p)`，其中 `p = 2²⁵⁶ − 2³² − 977`。加减乘除都在这个有限集合中算，除法用模逆。合法私钥的范围为 1 到 n−1，n 是基点 G 的阶（把 G 相加 n 次会得到群的单位元）。真实钱包从安全随机数或安全生成的种子派生密钥。下面的 d=2 是公开的演算参数，任何人都能为这把钥匙签名。

```python
p = 2**256 - 2**32 - 977
x = 0x79be667ef9dcbbac55a06295ce870b07029bfcdb2dce28d959f2815b16f81798
y = 0x483ada7726a3c4655da4fbfc0e1108a8fd17b448a68554199c47d08ffb10d4b8
slope = 3*x*x * pow(2*y, -1, p) % p
qx = (slope**2 - 2*x) % p
qy = (slope*(x-qx) - y) % p
pub = bytes([2 + qy % 2]) + qx.to_bytes(32, "big")
print(pub.hex())
```

这里算的是 2G，即 G 与自己相加。一般的标量可以按二进制位用倍点与加点得到 dG。将点压缩时，取前缀 `02` 表示偶数 y，`03` 表示奇数 y，再跟 32 字节大端 x。由 x 代回曲线方程和这个奇偶位就能恢复对应的 y。上例的 33 字节结果为 `02c6047f9441ed7d6d3045406e95c07cd85c778e4b8cef3ca7abac09b95c709ee5`。用该公钥的 HASH160 可以构造 Bob 的收款脚本。公开该点让别人可以验签，从一般安全随机生成的公钥反求私钥在计算上不可行。

压缩前缀 02 与 03 选取同一横坐标上不同的曲线点，编码出的公钥及其 HASH160 也随之不同。

**规范与实现**　[Standards for Efficient Cryptography 2 (SEC 2)](https://www.secg.org/sec2-v2.pdf)
