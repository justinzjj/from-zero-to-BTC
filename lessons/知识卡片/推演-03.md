# 从助记词派生收款地址与找零地址

Bob 给下一个买家出示另一个收款地址时，钱包可以从同一棵密钥树取下一个位置。备份了种子，并掌握路径、脚本类型及必要的钱包元数据，就可以重建相应密钥与脚本。

## 从助记词到 Bob 展示的收款地址

在采用 BIP39 的钱包里，初始化一次就能为后续收款准备一棵密钥树。以 12 词为例，钱包产生 128 位随机数，附上 SHA-256 摘要开头 4 位校验，再每 11 位查一次 2,048 词的词表。恢复时，以规范化（UTF-8 NFKD）的词句为密码，以同样规范化的 `mnemonic` 加可选口令为盐，用 PBKDF2-HMAC-SHA512 迭代 2,048 次得到 64 字节种子。之后由 BIP32 得到主私钥和链码，再逐层派生。一个普通子私钥可用于计算自己的公钥和地址；要重建整棵树，还需要种子或相应的根扩展密钥。不同钱包采用的备份形式可以不同，Core 描述符钱包也可从描述符跟踪脚本。

取一个子私钥 d，算公钥点 dG，将压缩公钥做 HASH160 得到 20 字节。收款脚本是 `00 14 <这20字节>`；主网地址把见证版本 0、这 20 字节和网络前缀 bc 按 Bech32 编码。Alice 扫码时反向解码，还原 Bob 交给她的花费条件。给出地址这一步可以在收到付款以前完成。

**对照公开样例。** 切换到 BIP84 官方测试钱包（与示例交易 B 分开）：11 个 `abandon` 后接 `about`，空口令。主网第一个账户的首个收款位置 `m/84'/0'/0'/0/0` 得到 `bc1qcr8te4kr609gcawutmrza0j4xv80jy8z306fyu`。内部派生分支的路径为 `m/84'/0'/0'/1/0`，对应同账户的首个找零地址 `bc1q8c6fshw2dlwun7ekn9qwf37cu2rn755upcp6el`。BIP39 按 MIT 保留许可声明可离线收录，BIP84 为 CC0。[BIP39](https://bips.dev/39/) · [BIP84 测试向量](https://bips.dev/84/#test-vectors)

**从种子开始。** HMAC-SHA512 接受一把 HMAC 密钥和一段消息，输出 64 字节。BIP32 建树时以 ASCII 字节 `Bitcoin seed` 为 HMAC 密钥，以种子原始字节为消息。把结果对半切开，左 32 字节解释为大端整数，合法时成为主私钥，右 32 字节是主链码。链码给下一次派生充当 HMAC 密钥。扩展私钥含私钥和链码，扩展公钥含公钥和链码。编码为 xprv/xpub 时还记录版本、深度、父指纹、子下标等字段，方便定位。

| 派生方式 | HMAC 的消息（最后 4 字节为大端下标） | 能从父扩展公钥推出子公钥吗？ |
|---|---|---|
| 普通，i < 2³¹ | 父压缩公钥 ∥ i | 能 |
| 硬化，i ≥ 2³¹ | 字节 00 ∥ 32 字节父私钥 ∥ i | 需要父私钥 |

两行都用父链码作 HMAC 密钥。输出左半作为整数 t，子私钥是 `(t + 父私钥) mod n`，右半成为子链码。普通派生还可直接算 `子公钥 = tG + 父公钥`。若 t ≥ n 或所得子私钥为 0，按规范进入下一下标。路径 `m/0'/1` 表示从主私钥先走硬化下标 0（实际编码 0x80000000），再走普通下标 1。

**换到 BIP32 官方测试向量 1。** 在 Python 运行下列三行，得到的主私钥开头为 `e8f32e723decf405`，主链码开头为 `873dff81c02f5256`。把 main[32:] 作密钥，以 `00 ∥ main[:32] ∥ 80000000` 作消息再算一次，子链码应以 `47fdacbd0f109704` 开头。

```python
import hmac
main = hmac.digest(b"Bitcoin seed", bytes(range(16)), "sha512")
print(main[:32].hex(), main[32:].hex())
print(hmac.digest(main[32:], b"\x00"+main[:32]+bytes.fromhex("80000000"), "sha512")[32:].hex())
```

收款分支的 xpub 可以派生普通子公钥。硬化派生需要父私钥；派生路径由钱包管理。

**英文术语**　HD（Hierarchical Deterministic，分层确定性）、SHA-256（Secure Hash Algorithm 256-bit）、HMAC-SHA512（Hash-based Message Authentication Code using SHA-512）、PBKDF2（Password-Based Key Derivation Function 2）、BIP（Bitcoin Improvement Proposal，比特币改进提案）。

**规范与实现**　[BIP32](https://bips.dev/32/#test-vector-1)
