# 换算并解码金额字节

1 BTC = 100,000,000 聪（sat），所以 1 聪是 **一亿分之一 BTC，即 0.00000001 BTC**。千分之一 BTC 已经有 100,000 聪，恰好是 Alice 这次选中的整个旧输出 U。

| 这次付款中的量 | 聪 | BTC |
|---|---:|---:|
| Alice 花掉的 U | 100,000 | 0.00100000 |
| Bob 的书款 B:0 | 60,000 | 0.00060000 |
| Alice 的找零 B:1 | 39,000 | 0.00039000 |
| 输入减去输出的手续费 | 1,000 | 0.00001000 |

**怎么用。** 从 BTC 换成聪就乘一亿，反向换算除以一亿。钱包可以切换显示单位。写入普通交易输出时，金额按整数聪编码，另有脚本规定这笔钱以后怎样花。节点读到的 B:0 前八字节是小端序的整数。用 Python 的 `int.from_bytes(bytes.fromhex("60 ea 00 00 00 00 00 00"), "little")`，结果为 60000。手续费 1,000 聪没有单独的输出，节点通过已知的 U 和两个输出求差。

钱包显示的 60,000 聪和 0.00060000 BTC 对应相同的交易金额字节。

**英文术语**　BTC（bitcoin，比特币的单位符号）、sat（satoshi，聪）。

**规范与实现**　[Bitcoin Core v29.0 的金额常量](https://github.com/bitcoin/bitcoin/blob/v29.0/src/consensus/amount.h#L9-L13)
